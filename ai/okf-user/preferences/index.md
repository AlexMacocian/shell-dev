# Preferences
* [Keep OKF memory public-safe](okf-memory-workflow.md) - Consult OKF, store public repository-level information, and use only minimal pointers for private Paperless documents.
* [Git commit signing with a USB YubiKey](git-commit-signing.md) - Commit signing needs a YubiKey touch: alert the user, or skip signing when working hands-off.
* [Ship Sherlock changes as releases, not local installs](sherlock-release-flow.md) - After changing Sherlock, bump VERSION, commit and push; the user runs `sherlock update`. Never go install temporary binaries.
